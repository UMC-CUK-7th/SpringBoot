# 🎯 핵심 키워드

- Domain

  ### 도메인 모델

  :도메인이라 불리는 개발 대상을 모든 사람이 동일한 관점에서 이해할 수 있고 공유할 수 있도록 단순화 시킨 것

  ### 도메인형 구조
  :각 도메인에 해당하는 디렉터리를 기준으로 파일들이 모이는 구조

  <br/>

    **장점**
    
    - 각각의 도메인 별로 패키지 분리가 가능하여 계층형 구조보다 관리가 직관적이다
    - 도메인과 관련된 스펙 & 기능이 변경되었을 때, 변경 범위가 적다
    - 유스케이스별로 세분화해서 표현이 가능하다
    
    **단점**
    
    - 애플리케이션의 전반적인 구조를 한눈에 파악하기가 어렵다
  
    <br/>

- 양방향 매핑

    **단방향 매핑**: 서로 다른 두 개의 엔티티 중 한 개의 엔티티 쪽에서만 참조하는 경우

    **양방향 매핑**: 모두 서로의 객체를 참조하는 경우

테이블의 경우 외래키를 이용해 서로의 테이블 데이터를 조회할 수 있기 때문에 사실상 양방향 관계라고 볼 수 있다.
